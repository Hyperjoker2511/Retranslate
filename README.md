# ReTranslate

**Translate novels — and anything else — on your Android phone.**

ReTranslate is a translator built for novel readers. Paste a chapter or import a whole book, and it translates with consistent names and terms from start to finish.

## Features

**Translate with no setup**
- Type or paste text and get a translation — no account, no key. The app tries its free engines automatically until one answers, and shows you which one did.
- Korean, Chinese, Japanese and many more languages.

**Made for novels**
- Import EPUB, TXT and PDF books and translate them chapter by chapter.
- The app learns each book's names and terms, so a character's name stays the same in chapter 1 and chapter 300.
- Paste a single chapter and choose: translate the original, or improve a machine-translated chapter you already have.
- **Improve with AI** — chapters you already translated can be polished in place. You see the before and after, and keep the version you like.
- **Consistency check** finds name and term mistakes across a whole book.

**Offline**
- Download language packs and translate entire books with no internet at all.

**Your keys, if you want them**
- Add your own AI key (Gemini and others) for higher-quality novel translation. Always optional — never required.

**Yours**
- Save results as files, back up your library, and read in a clean dark theme.

## Install

Download the APK from the Releases page and install it. Android 8.0 or newer.
